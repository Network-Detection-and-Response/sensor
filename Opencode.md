# Система анализа кибератак и поведения сети (Курсовая работа)

## Описание проекта
Мы разрабатываем распределенную систему обнаружения вторжений (IDS). Проект состоит из 4 модулей (Сенсор, Бэкенд, ML-модуль, Дашборд). 
**Текущий репозиторий:** Локальный Агент/Сенсор (Разработчик: Макар).

## Стек технологий сенсора
- Язык: C# 12 / .NET 8
- Библиотеки: SharpPcap / PacketDotNet (для перехвата трафика)
- Интеграция: HTTP-клиент (REST API) для отправки данных на бэкенд

## Глобальные правила кодинга (Критично!)
1. **Производительность:** Сенсор работает под высокой сетевой нагрузкой. Категорически избегать лишних аллокаций памяти в основном цикле обработки пакетов.
2. **Сборка мусора (GC):** Минимизировать создание объектов классов (`new`). 
3. **Современный C#:** Использовать `Span<T>`, `ReadOnlySpan<T>`, `Memory<T>` и `ArrayPool<T>` для работы с байтами пакетов. Использовать `struct` или `record struct` вместо `class` для агрегации метрик сессии (Flows).
4. **Асинхронность:** Отправка данных на сервер не должна блокировать поток перехвата. Использовать `System.Threading.Channels` (Producer-Consumer паттерн) и батчинг (отправка логов пачками раз в N секунд).

## Контракты данных
Сенсор не отправляет "сырой" трафик (payload). Он агрегирует пакеты в сессии по ключу: `IP Source + Port Source + IP Dest + Port Dest + Protocol`. 
Отправляемый JSON должен содержать количество пакетов, байт, флаги TCP и длительность сессии.
